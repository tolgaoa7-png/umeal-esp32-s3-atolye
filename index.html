PROJE 01 · GPIO

LED’i bağla ve yak

Montaj

USB’yi çıkar. LED uzun bacak (+) GPIO 4’e direnç üzerinden; kısa bacak (−) GND’ye bağlanır.

Direnç kullan. GPIO 4 örnek pildir; kart pinout’undan uygun GPIO’yu doğrula.

Kod

const int ledPin = 4;
void setup() { pinMode(ledPin, OUTPUT); }
void loop() {
  digitalWrite(ledPin, HIGH);
  delay(500);
  digitalWrite(ledPin, LOW);
  delay(500);
}
Kod ne yapıyor?
ledPin, GPIO numarasına isim verir. setup() açılışta bir kez çalışır ve pini çıkış yapar. loop() tekrarlanır: HIGH LED’i yakar, LOW söndürür. delay(500) yarım saniye bekletir.
PROJE 02 · I²C LCD

LCD’ye mesaj yaz

Kablo eşleştirmesi

ESP32-S3 3V3 → LCD VCC

ESP32-S3 GND → LCD GND

ESP32-S3 GPIO 8 → LCD SDA

ESP32-S3 GPIO 9 → LCD SCL

Yalnızca GND/VCC/SDA/SCL pinli I²C LCD içindir. I²C adresi çoğunlukla 0x27 veya 0x3F.

ESP32-S3 GPIO 3.3 V lojiktir. LCD modülünde 5 V pull-up varsa doğrudan bağlama. 16 pinli LCD farklı bağlanır.

Kod

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);
void setup() {
  Wire.begin(8, 9);
  lcd.init(); lcd.backlight();
  lcd.setCursor(0, 0); lcd.print("Merhaba!");
  lcd.setCursor(0, 1); lcd.print("ESP32-S3 hazir");
}
void loop() { }
Kod ne yapıyor?
Wire I²C haberleşmesini; LiquidCrystal_I2C LCD komutlarını sağlar. lcd(0x27,16,2): adres, sütun, satır. Wire.begin(8,9): SDA/SCL pinleri. init başlatır, backlight ışığı açar, setCursor yazı yerini seçer, print metni yazar. Mesaj sabit olduğu için loop boş kalır.
PROJE 03 · WI-FI

Telefondan LED’i kontrol et

Montaj ve açma

LED’i 220–330 Ω dirençle GPIO 4’e, kısa bacağını GND’ye bağla. WIFI_ADI ve WIFI_SIFRESI alanlarını doldur. Yükledikten sonra Seri Monitör’ü 115200 baud aç, IP adresini telefonda aç. Telefon ve kart aynı Wi-Fi’da olmalı.

Bu web sunucusu yerel ağ içindir. Parolanı paylaşma; dışarıya port yönlendirme açma.

Tam Arduino kodu

#include <WiFi.h>
#include <WebServer.h>
const char* ssid = "WIFI_ADI";
const char* password = "WIFI_SIFRESI";
const int ledPin = 4;
WebServer server(80);

void showPage() {
  server.send(200, "text/html",
    "<h1>ESP32-S3 LED</h1><a href=/on>AC</a> | <a href=/off>KAPAT</a>");
}

void setup() {
  Serial.begin(115200);
  pinMode(ledPin, OUTPUT);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) delay(300);
  Serial.println(WiFi.localIP());
  server.on("/", showPage);
  server.on("/on", []() { digitalWrite(ledPin, HIGH); showPage(); });
  server.on("/off", []() { digitalWrite(ledPin, LOW); showPage(); });
  server.begin();
}

void loop() { server.handleClient(); }
Kod ne yapıyor?
WiFi.h ağa bağlar; WebServer.h tarayıcı isteklerini karşılar. SSID ve parola ağ bilgilerini tutar. 80 web portudur. Bağlandıktan sonra localIP() adresi Seri Monitör’e yazdırılır. /on ve /off adresleri GPIO çıkışını değiştirir. handleClient() gelen istekleri sürekli dinler.

Web sunucu örneğini çalıştırmadan önce kart pinout’unu ve Wi-Fi bilgilerini doğrula.

Güvenli montaj

Pinout’u kontrol et

GPIO numaraları kart modeline göre kullanılabilir.
