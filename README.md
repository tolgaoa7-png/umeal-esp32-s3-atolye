# ÜMEAL · ESP32-S3 Atölye

Telefon ve bilgisayarda açılan Türkçe başlangıç rehberi. Tek bir statik HTML sayfasıdır.

## Projeler
- GPIO ile LED yakıp söndürme
- I²C LCD'ye mesaj yazdırma
- Wi-Fi ile LED kontrolü

Her projede malzemeler, montaj şeması, Arduino kodu ve kod açıklamaları bulunur.

## GitHub Pages
Pages, main dalındaki /(root) klasöründen yayınlanır. Site: https://tolgaoa7-png.github.io/umeal-esp32-s3-atolye/

## Donanım notu
GPIO numaraları örnektir. Kullanmadan önce kartının pinout şemasını ve LCD gerilim uyumunu kontrol et. ESP32-S3 GPIO pinleri 3.3 V lojiktir.
